# Архитектура библиотечной системы

## Обзор

Библиотечная система состоит из двух основных компонентов:
1. **Backend** - REST API на основе FastAPI, обеспечивающий все функциональные возможности системы
2. **Frontend** - GitHub Pages приложение, реализующее клиентский интерфейс

## Структура проекта

```

│   ├── __init__.py
```

## Backend архитектура

Backend реализован на FastAPI и предоставляет полный набор API эндпоинтов для управления библиотечной системой.

### Модули API

#### auth.py
- Регистрация и аутентификация пользователей
- Генерация и проверка JWT токенов
- Защита маршрутов с помощью middleware

#### books.py
- CRUD операции с книгами
- Валидация ISBN
- Проверка доступности экземпляров

#### readers.py
- CRUD операции с читателями
- Проверка уникальности email
- Проверка активных выдач при удалении

#### borrows.py
- Выдача и возврат книг
- Бизнес-логика ограничений (максимум 3 книги на читателя)
- Обновление количества доступных экземпляров

#### advanced.py
- **Бронирования** - система резервирования книг с очередью
- **Отзывы и оценки** - система отзывов с проверкой, что читатель брал книгу
- **Штрафы и оплаты** - система управления штрафами и обработки платежей
- **Статистика и аналитика** - дашборд, статистика книг, популярные книги
- **Уведомления** - система уведомлений пользователей

## Frontend архитектура

Frontend реализован как одностраничное приложение (SPA) с использованием чистого JavaScript, HTML и CSS.

### Основные компоненты

#### Аутентификация
- Регистрация и вход пользователей
- Хранение токенов в localStorage
- Управление состоянием авторизации

#### Управление книгами
- Добавление новых книг
- Просмотр списка книг
- Поиск и фильтрация (на стороне сервера)

#### Управление читателями
- Добавление новых читателей
- Просмотр списка читателей
- Поиск и фильтрация (на стороне сервера)

#### Выдача и возврат книг
- Интерфейс для выдачи книг читателям
- Интерфейс для возврата книг
- Проверка доступности книг

## Расширенные возможности

В backend реализованы дополнительные возможности, которые пока не интегрированы в frontend:

### Бронирования
- Система резервирования книг с очередью
- Поддержка приоритетов
- Управление сроками бронирования

### Отзывы и оценки
- Оценка книг по 5-балльной шкале
- Написание текстовых отзывов
- Валидация, что читатель брал книгу

### Штрафы и оплаты
- Автоматическое начисление штрафов
- Система оплаты с разными методами
- Отслеживание статуса оплаты

### Статистика и аналитика
- Дашборд с ключевыми метриками
- Статистика по отдельным книгам
- Анализ популярности книг

### Уведомления
- Система уведомлений для пользователей
- Поддержка разных типов уведомлений
- Статус прочтения

## API клиент

Frontend использует простую обертку для выполнения API запросов с автоматической обработкой аутентификации:

```javascript
async function apiRequest(endpoint, options = {}) {
    // Добавляет заголовок Authorization если есть токен
    // Обрабатывает ошибки
    // Возвращает JSON ответ
}
```

## Расширение функциональности

Чтобы добавить расширенные функции в frontend, разработчику нужно:

1. Добавить новые UI компоненты для отображения функций
2. Реализовать вызовы соответствующих API эндпоинтов
3. Обновить состояние приложения для работы с новыми данными
4. Обработать возможные ошибки и сценарии

Все необходимые эндпоинты уже доступны в backend, как описано в [api_endpoints.md](api_endpoints.md).
